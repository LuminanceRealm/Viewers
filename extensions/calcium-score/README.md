# Score de calcio coronario (NUBIX)

Extensión propia del fork. Resalta todo lo que supera 130 HU en una tomografía sin
contraste y deja que el radiólogo asigne cada lesión a una arteria con un clic; el
panel calcula el score de Agatston, el volumen y el número de lesiones por arteria.

Es una herramienta de apoyo cuantitativo: el resultado depende de que el estudio sea
el adecuado (CT cardíaca sin contraste, 120 kVp, cortes de ~3 mm) y de la asignación
manual del usuario.
